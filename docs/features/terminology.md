# 工作區名詞與統計定義

此文件是介面、API 說明與測試資料的名詞準則。功能名稱使用完整名稱，側欄、頁面標題與前往該頁的入口保持一致；數據標籤描述實際統計對象，不能以節點名稱推導跳轉文字。遵循 [W3C 連結目的與一致識別原則](https://www.w3.org/WAI/WCAG22/Understanding/link-purpose-link-only.html)。

## 功能名稱

| 功能 ID | 預設名稱 | 入口 | 用途 |
| --- | --- | --- | --- |
| dashboard | 總覽 | `/dashboard` | 查詢期間費用、用量與目前工作狀態 |
| chat | 對話 | `/chat` | 私人提問、AI 回覆與對話歷史 |
| files | 檔案庫 | `/files` | 個人已保存原檔，可重用於不同工作 |
| projects | 專案 | `/projects` | 共用指示、參考文件、提問範本與成果文件 |
| knowledge | 知識庫 | `/knowledge` | 有權限控制的文件集合、檢索與引用 |
| artifacts | 成果文件 | `/artifacts` | 可編輯、保存版本及匯出的工作成果 |
| shared | 分享 | `/shared` | 發送與閱讀具名、限時、唯讀的固定快照 |
| quality | 品質評測 | `/quality` | 回覆回饋、固定題庫與模型／指令比較 |
| repositories | 程式庫 | `/repositories` | 依個人 Gitea 權限閱讀程式與議題 |
| tasks | 背景任務 | `/tasks` | 文件文字擷取、索引與評測的持久任務 |
| integrations | 資料來源 | `/integrations` | 依來源權限查詢外部公文、校務資料 |
| admin | 平台管理 | `/admin` | 身分、功能授權、模型政策與稽核 |

功能名稱由 `accesscontrol.Features.Name` 維護，側欄、授權清單、頁面標題與總覽入口共用此名稱。管理員自訂名稱會沿用；前端載入前使用 `FEATURE_NAMES` 的預設值。變更預設名稱須同步 seed、增量 migration、前端預設及本表。名稱升級僅比對舊預設值，不覆蓋自訂名稱、啟用狀態、排序或授權。`介面元件` 是平台管理的子頁；`個人設定` 是帳號設定入口。

## 資源與處理

| 名詞 | 定義與邊界 |
| --- | --- |
| 檔案／原檔 | 已上傳的 binary；包含文件與圖片。同一 attachment ID 重用於多處，仍只保存一份。檔案庫僅列本人保存的原檔，不包含他人整個檔案庫。 |
| 附件 | 檔案在對話、知識庫或專案中的使用關聯，不是另一份原檔。未送出的草稿附件不一定已保存到檔案庫。 |
| 文件 | 用於閱讀或檢索的處理紀錄，包含擷取文字、頁面及處理狀態；也可能來自圖片。相同原檔可有多份獨立的文件紀錄與權限。不能將文件數當成檔案庫檔案數。 |
| 知識庫文件 | 已加入某個知識庫的來源文件。只有完成處理且仍有權限的文件可參與該知識庫檢索。 |
| 索引分段 | 知識庫文件切分後的檢索單位，以「段」計數。不是文件數、知識庫數或向量數；關鍵字檢索也會有分段。 |
| 文字擷取／OCR | 從原檔取得可閱讀文字；OCR 是圖片或掃描頁的文字辨識。不等於加入知識庫或完成可檢索索引。 |
| 文件處理完成 | 文件 `status=ready`；包含知識庫、專案及私有閱讀器紀錄。非知識庫文件完成處理後仍不會加入知識庫檢索。 |
| 可查詢 | 僅用於知識庫中已完成處理的文件；不套用到一般原檔或所有閱讀器文件。 |
| 需重新索引 | 已完成的文件含與目前 embedding profile 不符的分段；依新設定重新索引，與處理失敗分開統計。 |
| AI 回覆生成 | 等待或進行中的對話生成，對應 `Runs.ActiveOwnerId`。文件、文字工具與評測的模型呼叫不是這個數字。 |
| 背景任務 | 持久佇列任務。處理中包括 `queued` 與 `running`；失敗只包括 `failed`，不稱作所有「未完成」任務。 |
| 分享／共用 | 分享提供固定版本的唯讀快照與期限；共用是對原始專案、知識庫或成果文件授予閱讀／編輯權限。兩者不互換。 |

## 總覽與費用

- 檔案庫數字為 `counts.files`：目前範圍內 `InLibrary=true` 且原檔儲存完成的 attachment 數，不重複計算使用關聯，排除未保存的草稿與待刪除原檔。
- 知識庫節點為 `counts.collections`，單位「個知識庫」；`counts.chunks` 另以「段索引」顯示。專案數不代表知識庫數，兩者沒有從屬關係。
- 處理中工作為 AI 回覆生成數加背景任務數，單位「件」。文件處理完成／失敗及任務失敗分開列出。
- 「我的工作」依擁有者統計，並非所有共用給我的資源；「整個平台」須管理員權限，選取使用者後依該使用者統計。平台節點入口仍開啟目前帳號可存取的功能頁，不會轉為全平台資源列表。
- 費用、模型與工具呼叫、Token 使用量、趨勢及費用分布依查詢期間統計。工作狀態、資源數量與最近對話呈現目前狀況，不受費用日期篩選。
- 模型與工具呼叫涵蓋對話、網路搜尋、向量索引／檢索、OCR、文字工具與評測的計量紀錄。費用分布也包含工具，不只聊天模型。
- 區間已知費用只加總可結算金額；費用未知不是免費，待結算是尚未完成結算，不等同所有處理中的工作。API 計費估算、內部成本估算與免費依價格版本區分，不同幣別／類型不相加。總覽的費用未知次數涵蓋所有類型及早期未定價呼叫。
- Token 使用量是模型回報的輸入與輸出 token；個人存取權杖是 Gitea 的登入憑證，兩者名稱與用途分開。
- 檢索方式顯示「語意向量」或「關鍵字」。網路搜尋及 Gitea 的「已啟用」表示設定可用，不宣稱已完成即時遠端連線驗證。

API 欄位 ID、路由與歷史 migrations 保持技術命名，介面名詞調整不重寫歷史資料。詳細邊界見 [檔案庫](files.md)、[知識庫](knowledge.md)、[費用](billing.md)。

# 測試身分與切換登入方式

管理員可以用另一位使用者的身分檢查畫面與權限，不需要對方的密碼。所有開始、返回與到期都留下稽核。

## 切換登入方式

已登入的使用者可從帳號選單「切換登入方式」重新選擇 AD／Windows 或本地密碼。從本地切回 Windows 時，先以受 CSRF 保護的登出清除 cookie，再驗證 Windows 身分。

## 測試此身分

- 使用者操作選單的「測試此身分」要填寫目的。伺服器重新驗證管理權後，簽發 15 分鐘的測試 cookie，保存來源管理員與目標的 ID 與登入版本。
- 畫面持續顯示測試身分、來源與返回按鈕。切換時完整重新載入工作區：取消串流、清除記憶體資料與草稿狀態，其他分頁收到通知後重新載入。
- 測試期間目標的功能權限、資料 owner、配額與模型政策全部生效，新增或修改的業務資料會實際保存。
- 管理 API 在測試身分下只能讀取，禁止管理設定寫入與巢狀切換。
- 稽核同時記錄實際操作者（ActorId）與目標（OwnerId），管理清單與 CSV 都顯示兩者。每次測試有獨立識別碼，返回後舊 cookie 不能重播。

## 結束與失效

- 返回不要求目標具有管理權。登出、成功重新登入或到期都會結束測試並撤銷該次 cookie。
- 每次 request 重新檢查來源的登入與管理權：來源被撤銷時直接登出；目標被停用、改登入方式或到期時，只返回仍有效的來源管理員。
- 到期瞬間跨越身分的業務請求先以 409 阻擋，不會改用管理員身分執行；回應附身分識別，前端重新載入。
- 已建立的背景工作與已開啟的 SSE 依原生命週期完成，不會轉移 owner。
- 同一瀏覽器的分頁共用登入；要同時測試獨立登入，請用不同的瀏覽器 profile。

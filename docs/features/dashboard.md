# 總覽

結論：總覽是一次讀取（`GET /api/v1/dashboard`）組成的儀表板——上方是所選風格的主視覺，下方是可自訂的卡片。每個有權限的功能各有一張區塊卡片；費用與 Token 另有專屬卡片。名詞與統計口徑見 [名詞與統計](terminology.md#總覽與費用)，費用規則見 [費用](billing.md)。

## 看到什麼

| 卡片 | 內容 |
| --- | --- |
| 關鍵指標 | 區間已知費用、模型與工具呼叫、Token、處理中工作（AI 回覆生成＋背景任務），附每日走勢 |
| 費用趨勢、模型分布、Token 使用量 | 依查詢期間與所選幣別／費用類型；不同幣別與類型不相加 |
| 呼叫熱度 | 每日模型與工具呼叫的日曆熱圖 |
| 工作流程 | 原檔 → 背景任務 → 知識庫 → AI 回覆 → 成果文件 → 分享，只列有權限的功能 |
| 繼續工作 | 各功能中自己最近的對話、知識庫、專案、成果、任務與分享 |
| 服務狀態 | 檢索方式、網路搜尋、Gitea、模型服務與外部相依的設定或狀態，失敗排最前 |
| 各功能區塊 | 該功能的目前數量、期間數字（標「期間」）、每日走勢、分布、事實與自己的最近項目 |
| 使用者區間費用 | 只在「整個平台」：依使用者排序，「檢視」把整個總覽縮到該使用者 |

- 區塊只來自有權限的功能；平台、即時監控區塊只在管理員選「整個平台」且未指定使用者時出現。
- 清單中的標題一律是自己的工作，即使在「整個平台」範圍。
- 「我的工作」每 60 秒自動更新（分頁隱藏時暫停）；「整個平台」每次讀取都留稽核，只在按下重新整理或查詢時讀取。

## 風格

右上「總覽風格」切換，選擇存在這個瀏覽器、依帳號分開：

| 風格 | 特色 |
| --- | --- |
| 極光 | 漂移的極光背景、問候與目前狀態、三環指標（回覆完成率、回覆有幫助、文件可查詢）、毛玻璃卡片與游標聚光 |
| 星軌 | three.js 3D 星圖：各功能繞核心運行，大小依主要數字、有工作時粒子流動；點星體看細節。固定深色。沒有 WebGL 時改為平面環狀排列 |
| 脈衝 | 編輯式大字、每日呼叫心電圖、所有區塊數字的跑馬燈 |

減少動態（系統或個人設定）時動畫停在靜止畫面，3D 場景不旋轉。three.js 只在選擇星軌時載入。

## 自訂版面

「自訂版面」進入編輯：

- 拖曳卡片右上的握把，或聚焦握把後用方向鍵／Home／End 移動，位置會由螢幕閱讀器播報；拖到捲動區上下緣會自動捲動。
- 每張卡片可選 小／中／大／寬／滿版（12 欄中的 3／4／6／8／12 欄）、加高或隱藏；隱藏的卡片列在編輯列，可加回。
- 「恢復預設」清除這個範圍的自訂。
- 版面存在 `localStorage`，依帳號與範圍（我的工作／整個平台）分開，不同步到其他電腦；暫時沒有權限的卡片保留原位置，恢復權限後回到原處。新功能的卡片加在最後。
- 窄螢幕自動改為兩欄、手機一欄。

新增功能如何出現在總覽，見 [總覽區塊](../architecture/dashboard-sections.md)。

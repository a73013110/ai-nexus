# 總覽

結論：總覽是一次讀取（`GET /api/v1/dashboard`）組成的儀表板：頁首一句問候與目前狀態，下方是期間工具列與可自訂的卡片。每個人看到的版面相同，只有一種外觀，跟隨淺色／深色主題。每個有權限的功能各有一張區塊卡片；費用與 Token 另有專屬卡片。名詞與統計口徑見 [名詞與統計](terminology.md#總覽與費用)，費用規則見 [費用](billing.md)。

## 看到什麼

| 卡片 | 內容 |
| --- | --- |
| 關鍵指標 | 區間已知費用、模型與工具呼叫、Token、處理中工作（AI 回覆生成＋背景任務），附每日走勢 |
| 費用趨勢、模型分布、Token 使用量 | 依查詢期間與所選幣別／費用類型；不同幣別與類型不相加 |
| 呼叫熱度 | 每日模型與工具呼叫的日曆熱圖 |
| 工作流程 | 原檔 → 背景任務 → 知識庫 → AI 回覆 → 成果文件 → 分享，只列有權限的功能 |
| 繼續工作 | 各功能中自己最近的對話、知識庫、專案、成果、任務與分享 |
| 服務狀態 | 檢索方式、網路搜尋、Gitea、模型服務與外部相依的設定或狀態，失敗排最前 |
| 各功能區塊 | 該功能的目前數量、期間數字（標「期間」）、每日走勢、分布、事實與自己的最近項目 |
| 使用者區間費用 | 只在「整個平台」：依使用者排序，「檢視」把整個總覽縮到該使用者 |

- 區塊只來自有權限的功能。管理員看到的卡片與其他人相同（「整個平台」只多出使用者區間費用），即時監控只從側欄進入。
- 清單中的標題一律是自己的工作，即使在「整個平台」範圍。
- 「我的工作」每 60 秒自動更新（分頁隱藏時暫停）；「整個平台」每次讀取都留稽核，只在按下重新整理或查詢時讀取。

## 期間與幣別

- 期間用分段控制選 7 天／30 天／90 天／1 年／自訂；選「自訂」才顯示開始與結束日期。
- 每個選擇都自動套用：預設期間立即讀取，輸入日期停頓約 0.6 秒、且日期有效才讀取，所以沒有「查詢」按鈕。未完成或超出範圍的日期不會套用，匯出也沿用已套用的期間。
- 取捨：省掉按鈕、少一步；代價是「整個平台」每次套用都會留一筆稽核，所以日期等停頓才送出。重新讀取用頁首的重新整理。
- 幣別與費用類型、匯出費用（只在「整個平台」）是右側的膠囊按鈕。

## 自訂版面

「自訂版面」進入編輯：

- 拖曳卡片右上的握把，或聚焦握把後用方向鍵／Home／End 移動，位置會由螢幕閱讀器播報；拖到捲動區上下緣會自動捲動。
- 每張卡片可選 小／中／大／寬／滿版（12 欄中的 3／4／6／8／12 欄），任何尺寸都能直接換成其他尺寸；卡片窄時工具換到標題下一行，不會隱藏。也可加高或隱藏，隱藏的卡片列在編輯列，可加回。
- 「恢復預設」清除這個範圍的自訂。
- 版面存在 `localStorage`，依帳號與範圍（我的工作／整個平台）分開，不同步到其他電腦；暫時沒有權限的卡片保留原位置，恢復權限後回到原處。新功能的卡片加在最後。
- 看板窄於 60rem 時小／中改為半寬、大／寬改為整列，再窄（手機）一欄。
- 舊版存的風格設定不再讀取；已移除的卡片（平台、即時監控）在讀取已存版面時略過。

新增功能如何出現在總覽，見 [總覽區塊](../architecture/dashboard-sections.md)。

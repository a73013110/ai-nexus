# 對話

具有 `chat` 授權的使用者可以私人提問、保存回覆與歷史，重用檔案與知識來源。資料依帳號隔離；模型鎖定、名稱隱藏、思考能力與 Context 政策仍然適用。生成的流程與 SSE 見 [生成與背景任務](../architecture/generation.md)，個人設定與快捷鍵見 [個人設定](settings.md)。

## 聊天操作

| 功能 | 入口與行為 |
| --- | --- |
| 文件與圖片分析 | 輸入框旁的迴紋針、拖放或貼上圖片；歷史保留附件卡片，可預覽、下載、重新生成。見 [文件與圖片分析](attachments.md) |
| 常用提示詞 | 左側「常用範本」新增、編輯、刪除、套用；送出前仍可修改，每人最多 100 個 |
| 對話專屬指令 | 頂列「對話操作」→「對話指令與標籤」，最多 4,000 字元，套用於之後的生成 |
| 收藏 | 頂列星號；左側「收藏」篩選，收藏的對話優先排列 |
| 封存與還原 | 「封存對話」移出近期清單並暫停提問；在「封存」篩選中還原 |
| 標籤 | 以逗號分隔，最多 5 個、每個 24 字元；可與收藏、封存、文字搜尋組合 |
| 歷史搜尋 | 左側搜尋框比對標題與所有分支的訊息，點結果開啟原本選定的分支 |
| 個人草稿 | 提問文字與附件 ID 自動保存在目前瀏覽器，依帳號與對話分開 |
| 建立副本 | 保留全部分支、指令、標籤與附件關聯，建立新的對話與訊息 ID |
| 文字備份 | 匯出 JSON（全部分支、指令、標籤、附件名稱），左側上傳圖示匯入成新對話；Markdown 匯出目前可見的分支 |
| 對話內尋找 | 頂列搜尋圖示，在目前分支高亮並定位符合的訊息，上一則／下一則循環 |
| 快捷指令 | `Ctrl + K`，搜尋常用動作與歷史；方向鍵選擇、Enter 執行、Escape 返回原焦點 |

## 畫面

- 模型、思考強度與 Context 在輸入區；模型選單可搜尋、區分供應商，相同原生名稱可有各自的 Google／Ollama 路由。
- 「展開訊息輸入」開啟專注編輯視窗，草稿同步保留；兩種輸入區共用 Enter、換行、中文組字與字數上限規則。
- 回覆開始前顯示不定進度的訊號波形，串流開始後改為實際文字；動效遵循系統與個人的「減少動態效果」。
- 頂列雙擊（或 F2、鉛筆）修改對話名稱，Enter 儲存、Escape 取消，點外部也會儲存。提問靠右、回覆靠左，各有角色標示。
- 右側「對話定位」顯示目前輪次與總數；點橫槓跳到該輪提問，停留或聚焦顯示問答摘要，點輪次開啟完整目錄（手機用這個目錄）。
- 回答完成、取消或失敗後可展開耗時、排隊、執行與模型回報的 tokens，重新整理仍保留。

## 分支與重新生成

- 編輯歷史提問會新增分支；重新生成新增 assistant 的兄弟節點，都不覆寫舊訊息。
- 重新生成保留正在撰寫的草稿；編輯時可重用附件，移除只影響新分支，送出後恢復原本的提問草稿。
- 正在生成時要先停止，才能封存、複製、備份或刪除。副本的收藏與封存狀態重新開始。

## 草稿

- 存在 `localStorage`，不同步到其他裝置，不含檔案內容或憑證。每個帳號最多 40 份、每份 32,000 字元；儲存受限時保留目前輸入並提示無法保存。
- 登出會清除畫面與訂閱，再次登入可恢復該帳號的草稿。共用電腦上，作業系統與瀏覽器的使用者仍能讀取 localStorage；清除網站資料即可移除。

## 文字備份

- JSON 文字備份**不含附件原檔**，匯入後要重新上傳；上限 8 MB、400 則訊息、總計 1,000,000 字元。
- 匯入會檢查版本、父節點、角色順序與循環，不匯入 provider ID 或舊 run。
- 站內副本保留附件；完整備份需要同一時點的 SQL 與站外原檔目錄，見 [備份與還原](../operations/backup.md)。
- 刪除對話會保留檔案庫的原檔；要釋放容量，在沒有其他引用時從 [檔案庫](files.md) 明確刪除。

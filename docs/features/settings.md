# 個人設定與快捷鍵

## 個人設定

- 從側欄下方「登入者選單」→「設定」開啟，在目前頁面彈出，不切換網址、不送出問題、不清除草稿。
- 設定視窗在 app 根層延遲載入，開關時保留目前頁面的閱讀位置（只有改字級會依新高度重排）；標題與關閉按鈕固定在頂端。直接開啟 `/settings` 會在聊天背景開啟設定。
- 分類：外觀與閱讀、對話、通知、資料與草稿、帳號與權限、使用狀況、鍵盤快捷鍵；可搜尋分類。
- 外觀即時預覽，按「儲存變更」才保存到帳號；取消或放棄恢復已保存的設定，關閉未儲存的視窗會先確認。
- 對話正文與輸入字級 12–24px、行距 1–2.2；內容寬度、側欄寬度與訊息密度可調。一般介面維持固定字級。
- 「對話」顯示網路搜尋是否啟用；未啟用時輸入區不顯示該按鈕，原因與管理員該做的事在這裡，見 [聊天連網搜尋](web-search.md)。
- 通知需要瀏覽器權限，完成時只顯示一般提示，不含內容。
- 關閉「Enter 送出」後改用 Ctrl／⌘ + Enter；關閉本機草稿保存後，未送出的內容只留在目前畫面。
- 使用狀況顯示最近 30 天的用量（token 只計模型有回報的紀錄）與原檔容量（草稿計入，多處引用只計一次）。模型相關設定仍受管理員政策限制。

## 側欄

左側工作區依登入者的有效功能顯示，每個功能另外檢查資料權限；完整名稱保留在輔助閱讀標籤與滑鼠提示。

- **釘選**：上方放常用頁面（候選來自選單中的頁面），預設是前 4 項，最多 5 項；在「全部功能」按「自訂釘選」增減。目前所在功能以滑動的底色標示。
- **全部功能**：顯示伺服器依授權修剪過的選單樹（管理員在[存取管理](administration.md#選單)編排），每一格是一個頁面（一個網址），選單資料怎麼排就怎麼顯示；子分群以淺色區塊包在上層之內，已釘選的留在原位並以圖釘標示。分群標題可點擊或用鍵盤展開／收合，換到某頁時它所在的分群自動展開；收合不影響釘選與 Ctrl+K。有側欄內容的頁面（對話、介面元件）把它收在釘選列，展開時暫代側欄內容；其他頁面直接列在下方。
- **外部連結**：選單可含管理員加入的外部系統連結，以外部連結圖示標示，依設定在新分頁或目前分頁開啟（一律 `noopener`）；Ctrl+K 也搜得到。連結沒有站內網址，不能釘選，也不會標示為目前所在。
- **顯示方式**：「圖示」把釘選排成一列，讓對話歷史保留高度；「條列」每個功能一行並顯示名稱。
- 釘選、顯示方式與收合的分群依帳號存在這個瀏覽器，只影響呈現、不影響授權。
- 所有頁面共用右上的收合切換：收合成圖示欄時保留釘選、通知與帳號，「全部功能」與登入者選單改從旁邊彈出；手機改成抽屜。版面規則見 [共用介面模式](../frontend/ui-patterns.md#導覽)。
- 對話歷史依收藏、今天、昨天、過去 7 天、過去 30 天、更早分組（瀏覽器時區）；每列的「⋯」開啟同一個操作選單。

## 快捷鍵

| 按鍵 | 用途 |
| --- | --- |
| `Enter`／`Shift + Enter` | 送出／換行；中文 IME 組字不會誤送 |
| `Ctrl + K`（macOS `⌘ + K`） | 快捷指令：搜尋全部功能、目前頁面的動作與對話 |
| 對話歷史中的 `↑`／`↓`、`Home`／`End` | 在對話之間移動；搜尋框按 `↓` 進入清單 |
| `Ctrl + Alt + N` | 新對話 |
| `Ctrl + Shift + L` | 提示詞範本 |
| 尋找列中的 `Enter`／`Shift + Enter` | 下一則／上一則符合的訊息 |
| `Escape` | 關閉目前的浮層、dialog 或手機導覽並返回焦點 |
| `F2` | 修改目前對話名稱 |

所有下拉選單用同一個元件：方向鍵選取、Home／End 定位、Enter 確認、Escape 或點外部關閉。

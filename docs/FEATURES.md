# 工作台功能指南

左側工作區依登入者的有效功能顯示；每個功能還會檢查自己的資料權限。聊天頁使用精簡的圖示入口，保留更多歷史空間。一般功能頁提供完整名稱，手機可橫向瀏覽導覽列。

| 工作區   | 最直接的操作                                             | 詳細說明                        |
| -------- | -------------------------------------------------------- | ------------------------------- |
| 專案     | 先選專案，再用範本建立私人提問，文件／指示自動帶入       | [專案](PROJECTS.md)             |
| 知識庫   | 上傳文件，於輸入框「來源」選取，回答附原文引用           | [知識庫](KNOWLEDGE.md)          |
| 成果     | 回答旁直接另存，或選取段落改寫／翻譯／摘要，儲存為新版本 | [成果](ARTIFACTS.md)            |
| 分享     | 內容旁選收件人及期限，對方登入後直接閱讀固定快照         | [分享](SHARING.md)              |
| 品質     | 回答旁一鍵回饋；固定題庫比較模型／指令，再補人工評分     | [品質](QUALITY.md)              |
| 背景任務 | 直接查看階段、停止／重試，離開頁面仍繼續                 | [文件任務](KNOWLEDGE.md)        |
| 個人設定 | 搜尋分類、即時預覽，再儲存外觀／閱讀／操作偏好           | 本頁下方                        |
| 平台管理 | 管理員調整角色／群組／功能與配額，查看有效授權及稽核     | [管理](ADMINISTRATION.md)       |
| 系統整合 | 查受控來源的本文／版本／歷程，另存或帶到聊天草稿         | [來源啟用條件](INTEGRATIONS.md) |
| 介面元件 | 平台管理頁右上方開啟；檢查實際元件的主題與互動           | [設計系統](DESIGN_SYSTEM.md)    |

以下 12 項聊天擴充由具有 `chat` 授權的使用者操作，資料依帳號隔離。模型鎖定、名稱隱藏、思考能力及 Context 政策仍適用。

| 功能              | 操作入口與行為                                                                                                  |
| ----------------- | --------------------------------------------------------------------------------------------------------------- |
| 1. 文件與圖片分析 | 輸入框旁的迴紋針，亦可拖放檔案或貼上剪貼簿圖片。輸入處理任務後送出；歷史保留附件卡片，可預覽、下載與重新生成。  |
| 2. 常用提示詞     | 左側「常用範本」可新增、編輯、刪除及套用。點選範本帶入提問，送出前仍可修改；每人最多 100 個。                   |
| 3. 對話專屬指令   | 頂列「對話操作」→「對話指令與標籤」。設定語氣、格式或工作背景，最多 4,000 字元，套用於此對話之後的生成。        |
| 4. 收藏           | 頂列星號收藏／取消；左側「收藏」篩選。收藏的對話在歷史中優先排列。                                              |
| 5. 封存與還原     | 「對話操作」→「封存對話」，移出近期清單並暫停提問；於「封存」篩選還原後接續。                                   |
| 6. 對話標籤       | 「對話指令與標籤」以逗號分隔，最多 5 個、每個 24 字元。左側標籤可搭配收藏、封存和文字搜尋。                     |
| 7. 歷史內容搜尋   | 左側搜尋框同時比對標題與所有分支訊息；點選結果開啟原先選定的分支。                                              |
| 8. 個人草稿       | 提問文字與附件 ID 自動保存在目前瀏覽器，依帳號與對話分開，重新整理後恢復；新對話有自己的草稿。                  |
| 9. 建立副本       | 「對話操作」→「建立對話副本」，保留全部分支、指令、標籤及附件關聯，建立新的對話／訊息 ID。                      |
| 10. 對話文字備份  | 匯出 JSON 保存全部分支、指令、標籤及附件名稱；左側上傳圖示匯入新對話。Markdown 匯出保留目前可見分支，方便閱讀。 |
| 11. 對話內尋找    | 頂列搜尋圖示；在目前分支比對內容、顯示符合訊息數量、高亮並定位，上一則／下一則循環切換。                        |
| 12. 快捷指令      | 左側快捷圖示或 `Ctrl + K`；搜尋常用動作及目前歷史，方向鍵選擇、Enter 執行、Escape 關閉並返回原焦點。            |

## 快捷鍵

「個人設定」提供外觀與閱讀、對話、通知、資料與草稿、帳號與權限、使用狀況及鍵盤快捷鍵。外觀即時預覽，按「儲存變更」後保存到帳號；取消或離開恢復已保存設定。字級 16–24px、行距 1.5–2.2、內容寬度、側欄寬度與訊息密度可調整。通知需瀏覽器權限，完成時只顯示一般提示，不包含內容。

所有下拉選單採同一個主題元件，方向鍵選取、Home／End 定位、Enter 確認、Escape／點外部關閉。模型設定仍遵守管理員政策。關閉 Enter 送出後，使用 Ctrl／⌘ + Enter；關閉本機草稿保存後，未送出內容只保留在目前畫面。個人用量涵蓋最近 30 天，token 合計只計模型有回報的紀錄。

目前對話名稱可在頂列雙擊直接修改，Enter 儲存、Escape 取消；也可按 F2 或點鉛筆，適用鍵盤與手機。點擊輸入框等外部區域會儲存修改。提問靠右、AI 回覆靠左，兩者各有明確的角色標示。

右側「對話定位」顯示目前輪次與總數。點橫槓可直接跳到提問；滑鼠停留或鍵盤聚焦會顯示該輪的問答摘要。點輪次可開啟完整目錄，手機以此目錄操作。

| 按鍵                                | 用途                                      |
| ----------------------------------- | ----------------------------------------- |
| `Enter`／`Shift + Enter`            | 送出／換行；中文 IME 組字不會誤送         |
| `Ctrl + K`（macOS 為 `⌘ + K`）      | 快捷指令                                  |
| `Ctrl + Alt + N`                    | 新對話                                    |
| `Ctrl + Shift + L`                  | 提示詞範本                                |
| 尋找列中的 `Enter`／`Shift + Enter` | 下一則／上一則符合訊息                    |
| `Escape`                            | 關閉目前浮層、dialog 或手機導覽並返回焦點 |

模型、思考強度與 Context 留在輸入區。長提問自動增高至設定上限；手機導覽採抽屜。生成時顯示 SVG 訊號與文字游標，結束即停止；動效遵循系統與個人「減少動態效果」。

## 保存與備份規則

草稿使用 `localStorage`，不會同步到其他裝置，不包含檔案二進位或憑證。每位帳號最多 40 份、每份最多 32,000 字元；儲存受限時保留目前輸入並顯示無法保存。登出清除畫面與訂閱，該帳號草稿可於再次登入恢復。共用電腦上，作業系統及瀏覽器使用者仍能存取 localStorage；清除網站資料即可移除本機草稿。

重新生成保留正在撰寫的草稿；編輯歷史提問時可重用附件，移除只影響新分支。送出編輯分支後恢復先前正常提問草稿。副本採新的收藏／封存狀態。正在生成時，需先停止才可封存、複製、備份或刪除。

JSON **文字備份不含附件原始檔**，匯入後需重新上傳；上限 8 MB、400 則訊息、總共 1,000,000 內容字元。匯入檢查版本、父節點、角色順序及循環，不匯入 provider ID 或舊 run。站內副本保留附件；完整備份需包含 SQL 的所有業務 schema。刪除最後一個引用附件的對話會釋放檔案及配額，副本仍引用的檔案保留。

PDF 優先抽取原生文字，掃描頁經背景 OCR；完成前暫停送出，可在閱讀器核對原文。DOCX 抽取段落及表格，不讀內嵌圖片／巨集；圖片聊天直接交給核准的圖片模型。格式與設定見 [文件與圖片分析](ATTACHMENTS.md)。

## 更新與快速運行

已有本機參數與套件時，在根目錄執行：

```powershell
./scripts/Initialize-Database.ps1
./scripts/Start-Local.ps1
```

Initialize 只套用未完成的 migration，保留既有資料。Start-Local 建置後由一個 ASP.NET host 提供前端及 API，開啟 [工作台](http://localhost:5080/chat)。開發熱更新使用 `./scripts/Start-Dev.ps1`。詳見 [參數設定](CONFIGURATION.md)、[開發與執行](DEVELOPMENT.md)、[資料庫](DATABASE.md)。

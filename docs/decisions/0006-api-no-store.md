# 0006 API 一律不快取

- **狀態**：採用（2026-10）
- **決定**：`/api` 回應一律 `Cache-Control: no-cache, no-store`（`AiNexus.Platform/Security/WebSecurity.cs`），不做 output caching 或 ETag。前端只對參考資料（模型目錄、搜尋狀態、附件政策）在瀏覽器記憶體快取 30 秒，身分變更或任何非 GET 請求就清除。

## 原因

- 幾乎所有回應都是個人資料或依授權而變；授權每個 request 由 SQL 重新計算，撤銷要在下一次操作生效。伺服器端快取很容易把一個人的資料交給另一個人，或讓撤銷延遲生效。
- 單一學校的流量不需要伺服器快取；真正的成本在模型呼叫，由配額與 rate limit 控制。
- 前端的短期記憶體快取只放不含個人內容的參考資料，避免頁面切換時重複請求。

## 何時重新評估

出現明確的熱點查詢、且結果不依使用者而變時，針對該端點個別評估，不全域開啟。

# 0007 不保留舊版相容

- **狀態**：採用（2026-10-09，Yikai 確認）
- **決定**：目前只有一位使用者，沒有需要相容的正式資料或舊設定。資料庫 migration 重建為單一 `InitialCreate`；設定只有一個版本，沒有版本號與遷移工具；不保留舊 API 路徑或舊設定鍵的轉換程式。

## 原因

- 相容層（設定 v1→v3 遷移、舊檔拆分、14 個 migration 的升級路徑）是維護負擔，卻沒有任何資料需要它。
- 設定以 `ErrorOnUnknownConfiguration` 綁定，拼錯或舊版的鍵在啟動時就失敗並指出鍵名，比默默忽略更安全。

## 代價

2026-10-09 以前建立的資料庫無法升級，必須刪除重建；舊的 `.local` 與 IIS 設定要手動改成新鍵名。

## 何時重新評估

有第二位使用者或正式資料後，之後的 schema 變更一律追加具名 migration，不再重置基線；設定鍵改名時要提供過渡期。

# 0037 Gitea 儲存庫權限改為逐人授予

- **狀態**：採用（2026-11-13）；操作與上線步驟見[儲存庫權限](../features/repository-access.md)。
- **背景**：Gitea 1.26.2 以 HLAD（LDAP）登入，原本靠組織團隊授權：儲存庫不是私有（「組織內部用」），組織成員都能讀。為了資安，改成每個儲存庫逐人設定協作者，經[簽核](0036-approval-engine.md)或由負責人直接授予。
- **決定**：
  - 做成 `Repositories` 模組（程式庫）的新能力，沿用同一份 Gitea 設定，全系統只有一個 Gitea 整合。
  - **授權以 AI Nexus 為準**：`RepositoryGrants` 每人每庫只有一筆有效授權，記權限、到期日、來源與核准的申請。排程任務 `repositories.access-sync`（每 5 分鐘）是唯一寫入 Gitea 的地方，每一輪都把協作者調成與授權一致：缺的加上、權限不同的修正、撤銷或到期的移除；每 `ReapplyHours` 小時把有效授權全部重寫一次。核准或撤銷後立刻要求跑一輪。
  - **只動自己登記的協作者**：Gitea 上沒有授權紀錄的協作者列在儲存庫的權限詳情，由管理員轉成平台授權或在 Gitea 移除。已登記的協作者若被人在 Gitea 手動移除，下一輪會加回來；要撤銷請在 AI Nexus 操作。
  - **服務帳號**：建一個專用 Gitea 帳號，設為所有組織的 Owner。權杖只給 `write:repository`、`read:organization`、`read:user`，放在秘密設定 `Repositories:Gitea:ServiceToken`；空白時整個功能停用。不用網站管理員權杖；使用者瀏覽程式庫仍用自己的權杖，不經過服務帳號。
  - **範圍**：服務帳號所屬組織的全部儲存庫自動同步成目錄，新發現的預設開放申請；個人帳號底下的不納管。
  - **帳號對應**：Gitea 登入名＝使用者的 AD 帳號。人員授權存 UserId，同步時以目前的 AD 帳號換算登入名；送出申請與授予前，先用服務帳號確認 Gitea 有這個帳號。部署用等非人員帳號，只有管理員能以 Gitea 登入名授予，且必須填理由。
  - **權限**：申請與負責人直接授予只能給 read、write；admin 只有管理員能給。協作者沒有 Gitea 團隊那種逐單元（程式碼、問題、Wiki）的權限。
  - **誰能授予**：
    - 申請要經過簽核。
    - 儲存庫負責人（可多位）可以直接授予、撤銷、改到期日，不經簽核。
    - 管理員全部都能做。
    - 直接授予與撤銷都記稽核，並通知當事人。
  - **流程**：申請種類 `repository-access` 提供事實 `permission`（read／write）與審核人規則 `repository-stewards`。預設流程是「主管 → 負責人」；只有寫入才要主管等分流，用關卡條件設定，不為個別儲存庫另建流程（[ADR 0036](0036-approval-engine.md)）。
  - **到期**：申請時可填到期日。到期由同步任務撤銷，到期前 `ExpiryNoticeDays`（預設 7）天通知本人與負責人。定期覆核留到第二階段。
  - **離職**：依 [ADR 0019](0019-account-disable-and-departure.md) 不自動撤銷，帳號覆核多一項：「帳號已停用，仍有儲存庫權限」。
- **原因**：
  - 期望狀態加上單一同步者：Gitea 呼叫失敗、停站、到期，都由下一輪收斂，不需要補償或重試佇列。只有一個程序寫 Gitea，不會互相搶寫。
  - 授權綁 UserId 而不是登入名：依 ADR 0019 改綁 AD 帳號時，不必改授權。
  - 負責人比主管更清楚程式碼能給誰；主管忙的時候由負責人處理。需要主管把關的儲存庫，在流程裡加主管關卡即可。
- **上線前 Gitea 要做的**（不做的話，逐人授權沒有效果）：
  1. 建立服務帳號，設為 4 個組織的 Owner；Owners 團隊只留最少的人。
  2. HLAD 認證來源開啟使用者同步：新人不必先登入 Gitea 一次；AD 停用時 Gitea 帳號一併停用。否則個人權杖與 SSH 金鑰在離職後仍可使用。
  3. 公告期間先讓大家申請。授權生效時團隊還在，不影響工作。
  4. 切換日把儲存庫改為私有，並移除 Contributors、RD、Servers 對儲存庫的存取。`Servers` 若是部署用帳號，改用部署金鑰，或由管理員以登入名授予。
  5. 盤點個人帳號底下 fork 的私有庫，並考慮關閉私有庫的 fork。
- **取捨**：
  - 同步每 5 分鐘一輪，Gitea 端手動加的協作者最多 5 分鐘後才會列為未登記。
  - 不管理 Gitea 團隊：仍有團隊授權存取時，目錄只顯示警告，不代為移除。
  - 撤銷只收回伺服器上的存取，已 clone 或 fork 的副本收不回。

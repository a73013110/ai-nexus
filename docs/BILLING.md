# 模型費用與使用量

每則 AI 回覆下方提供本次呼叫的費用與 tokens；目前對話上方的費用按鈕顯示全對話總額。總覽可選 7／30／90 天或日期區間，管理員切換「整個平台」後，可查各使用者、模型及每日金額，並匯出 CSV。不同幣別與 API／內部成本各自顯示，不進行隱含匯率換算。

## 設定價格

總覽與個人設定共用 `TokenUsageChart`，顯示每日輸入／輸出／合計，可篩模型、查看模型分布及完整回報比例。沿用 SVG TrendChart 的鍵盤、深色、窄螢幕、減少動態支援，無新增圖表依賴或 License。

`tokens` 為 `{ from, until, timezoneOffsetMinutes, daily }`，daily 包含 `date, modelId, modelDisplayName, requests, requestsWithUsage, inputTokens, outputTokens`。從 Runs／ModelInvocations 聚合，含沒有價格快照的舊呼叫及 OCR／評測／review 等背景模型呼叫，不依費用是否可結算決定 Token 數。缺少回報不當成已知零值，合計只加已回報數字，完整回報比例另外呈現；無呼叫日期補零維持連續時間軸。總覽沿用所選時區／owner／區間，個人設定為最近 30 日 UTC，模型識別遵循平台顯示政策。

管理員在管理頁或總覽開啟「模型與工具價格」，新增價格版本：

| 欄位 | 設定方式 |
| --- | --- |
| 供應商／模型或工具 | 選擇供應商，再以 DisplayName 選取已設定的模型、知識向量模型或網路搜尋；後端保留供應商與原生 ID 作為計費鍵 |
| 幣別 | USD／TWD 等三碼幣別；同一期間可以有不同幣別的歷史費用 |
| 費用類型 | `api` 是對外 API 估算；`internal` 是自行制定的本機成本；`free` 明確表示此模型免費 |
| 輸入／快取輸入／輸出 | 每百萬 tokens 的價格。快取輸入不得高於一般輸入；完全相同價格可不區分快取 |
| 每次固定費用 | 可與 token 價格合併，例如內部一次處理成本，或搜尋單次費用 |
| 單次計費時機 | 成功完成時，或已開始呼叫時（包含失敗／取消）。此選項只控制固定費用，token 費依有效用量計算 |
| 生效時間／備註 | 留空立即生效；可排定未來版本，記錄官方價格、合約日期或內部估算依據 |

系統不預填某一家供應商的價格，也不推定本機模型為零成本。不同帳號的方案、折扣、免費額度與計費方式可能不同，請依實際方案輸入。「價格歷史」可帶入舊設定，再儲存成新版本；最新 500 個版本可在視窗中瀏覽，所有歷史仍保留於 SQL。

## 計算與歷史

呼叫建立時將適用價格複製到 `inference.ModelCharges`，價格更新、中途換模型、重新生成及切換分支都不會重算舊紀錄。呼叫 ID 同時是費用紀錄主鍵，重送同一 Idempotency-Key 不會再計費。

```text
金額 = (輸入 tokens − 快取 tokens) × 輸入單價 / 1,000,000
     + 快取 tokens × 快取單價 / 1,000,000
     + 已計費輸出 tokens × 輸出單價 / 1,000,000
     + 適用的每次固定費用
```

Google 的 prompt tokens 包含快取，輸出統計另有 thoughts tokens。本系統將候選回答與 thoughts 合併為已計費輸出，思考數量只作子項顯示，不再加第二次。只有串流完整結束且有有效用量才能按 tokens 結算；供應商未完整回報時不以字數猜測帳單。[Google UsageMetadata](https://ai.google.dev/api/generate-content#UsageMetadata)

金額使用 SQL `decimal(20,8)`，結算到小數點後 8 位。瀏覽器顯示是估算，真正對外帳單以供應商為準。多模型使用各自的價格快照，全對話包含所有分支、重新生成與搜尋呼叫；embedding、OCR、成果文字工具與評測另外計入期間用量，不強行歸入某個對話。

| 狀態 | 意義 |
| --- | --- |
| `pending` | 等待或執行中，尚未結算 |
| `metered` | 已按有效用量或固定費率計算；明確免費版本可為 0 |
| `unpriced` | 當時沒有價格，金額未知 |
| `missing_usage` | token 價格需要的用量未完整回報，金額未知 |
| `not_started` | 取消或授權失效等使模型未被派送，金額為 0 |

失敗／取消的已派送呼叫可能仍有費用，依有效用量與固定費率處理。未知費用不當成免費。升級前的呼叫顯示為「早期呼叫尚無價格紀錄」，不回填推測價格。總覽的「已知費用」只加總可結算紀錄，另外顯示未知、早期與待結算次數。

## 時間、權限與 API

期間使用開始含／結束不含；網頁所選結束日期含當天，送出時轉為隔天零點。每日分組依瀏覽器時區，API 預設 UTC+8，可用 `offsetMinutes` 明確指定固定偏移。單次最多 366 天；跨夏令時間的每日分組目前使用查詢開始日的固定偏移。費用歸屬呼叫建立日期，不是供應商出帳日期。

| API | 權限 |
| --- | --- |
| `GET /api/v1/billing/spend` | 已登入，只查自己 |
| `GET /api/v1/conversations/{id}/spend` | chat 權限且為對話擁有者 |
| `GET /api/v1/admin/billing/targets` | 平台管理員；已設定的模型與工具及其顯示名稱 |
| `GET/POST /api/v1/admin/billing/prices` | 平台管理員；新增版本，沒有修改／刪除歷史接口 |
| `GET /api/v1/admin/billing/spend` | 管理員，選用 ownerId、from、until、offsetMinutes |
| `GET /api/v1/admin/billing/export` | 管理員，相同條件，完整使用者彙總 CSV |
| `GET /api/v1/dashboard` | dashboard 功能；platform 範圍額外需要 admin |

所有網頁模型標籤只顯示 DisplayName，管理報表與價格歷史也遵循此規則。一般使用者仍依模型隱藏政策顯示「AI 助理 N」；已移除模型顯示通用標籤，完整 ID 只作為路由、統計或計費參照。平台總覽的最近對話標題仍只顯示管理員自己的工作；查看其他人的對話使用原有管理頁並留下稽核。新增價格、平台報表／總覽讀取和匯出都留稽核。CSV 對文字欄位處理公式開頭，避免開啟檔案時把帳號或名稱視為試算表公式。

目前估算支援一般／快取輸入、輸出與固定費用。批次 API、階梯用量、長 Context 分段定價、匯率換算及供應商帳單調節尚未實作；不要用單一線性費率冒充這些方案的精確帳單。

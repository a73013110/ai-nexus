# 專案工作區

專案集中管理共用指示、參考文件、提問範本與成果文件。具名成員可為讀者或編輯者；群組授權仍為唯讀。附件／成果沿用專案 ACL，撤銷成員權限後會停止繼承。

每次專案提問會帶入當時的共用指示與已完成辨識的參考文件，並保存於生成參數。排隊工作在呼叫模型前再次檢查權限。Context 預覽也包括專案資料。最多 50 份檔案，完整參考文字最多 12,000 字元及 100 頁；超量或仍在 OCR 的文件會明確提示，避免悄悄忽略來源。較大量資料應加入知識庫進行 ACL 篩選後的檢索。

「我的專案對話」只列出自己的提問。共享背景不代表公開所有成員的私人對話；需要給同事看時，另建立具名、到期的唯讀分享。範本按一下即建立專案對話並把提問放進輸入框，仍由使用者按送出。

專案封存後保留文件與歷史，停止新增對話／範本／附件。共用指示採版本條件更新，衝突保留表單文字。成果保留原本的不可變版本策略。

`projects.Projects` 保存共用指示、說明、版本與封存狀態，`projects.ProjectTemplates` 保存常用提問；`collaboration.Resources.ParentId` 僅允許受控服務建立一層專案子項目。`conversations.Conversations.ProjectId` 關聯私人對話，`content.Artifacts.ProjectId` 關聯共用成果。文件仍使用 knowledge 文件／頁面與同一套背景任務。

# 品質回饋與固定評測

AI 回覆下方可直接按「有幫助」或「待改善」，再按一次會移除回饋。原因及補充文字是選填；僅原始對話擁有者能提供回饋，「品質評測 → 我的回饋」可回到對話。

評測集包含 1–20 個固定問題、參考答案、必要詞及禁用詞。每題問題及參考答案各最多 4,000 字元，詞表各最多 20 個、每詞 80 字元。題庫可匯出／匯入 version 1 JSON，以便保存團隊的代表案例。修改使用版本檢查，衝突時保留尚未儲存的輸入。

每次執行可設定 1–3 個模型／提示詞方案，各方案指令最多 4,000 字元。模型必須經伺服器與群組政策核准；系統鎖定模型時，僅使用指定模型。模型名稱隱藏政策同樣適用。每個答案計入共用模型用量及配額，參考答案與檢核詞不會提供給模型。

執行會凍結題庫版本、問題、方案及模型設定摘要（Context、輸出上限、temperature、思考強度）。設定指紋也包含提供者、端點與模型 ID 的雜湊，不包含 API key，也不將端點或隱藏模型名稱傳給瀏覽器。排程執行／重試前若設定變更會明確失敗，必須建立新的比較；舊版缺少指紋的待執行任務同樣需重建，已完成結果仍可讀取。這使設定可追溯，但不保證模型輸出相同，提供者也可能更新模型。

背景任務保存逐題結果，離開頁面不會停止；停止／失敗後重試會跳過已完成的結果。未完成的一次外部模型呼叫若遇到程序中斷，可能在重試時重新呼叫，提供者不支援跨程序 exactly-once。

結果列出實際回答、耗時、提供者回報的 tokens、必要詞涵蓋數、禁用詞出現數及截斷狀態。這些是**文字檢核指標，不是語意正確率**，例如否定句仍可能包含必要詞。編輯者可以補人工 1–5 分與判讀說明，與自動指標分開保存。

題庫沿用共用 ACL：擁有者／具名編輯者可改題目與人工評分，讀者可查看及以自身配額建立比較；群組授權僅提供檢視。**題庫的授權成員可以閱讀其中所有比較結果與指令**，請使用適合團隊分享的案例。個人聊天回饋不因此公開。

`quality.MessageFeedback` 保存個人回饋；`EvaluationSets` 保存目前題庫與版本；`EvaluationRuns` 保存執行時的不可變快照及背景任務；`EvaluationResults` 以執行／題目序號／方案序號為鍵，保存完成答案、指標及人工判讀。權限撤銷會阻擋後續閱讀、執行與重試。

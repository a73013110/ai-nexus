# 功能生命週期與增刪修策略

依目前模組逐項檢查，容器與內容採擁有者／ACL／版本控制；外部資料、稽核和計量則保留可追溯性。以下是實際操作範圍，沒有把所有資料表都直接做成管理表單。

| 功能                   | 新增／查詢                                        | 修改                                                 | 移除與限制                                                                                                             |
| ---------------------- | ------------------------------------------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 私人對話               | 新建、搜尋、標籤、匯入／匯出                      | 雙擊標題、收藏／封存、編輯提問形成分支、重新生成版本 | 擁有者刪除，保留稽核；不能刪另一人的對話                                                                               |
| 對話生成               | 排隊、SSE、斷線續接、用量                         | 停止、失敗後手動重新生成                             | 不改寫既有回答；保存部分輸出與具體失敗原因                                                                             |
| 範本                   | 個人範本及專案共用範本                            | 名稱／內容                                           | 有權限者刪除；不影響已送出的訊息                                                                                       |
| 附件／圖片             | 上傳、原始檔與閱讀器、OCR                         | 原始檔不可就地篡改；重新上傳建立新文件               | 未綁定草稿刪除／逾期清理；已有引用時避免刪到其他資源                                                                   |
| 個人文件               | 最新 200 份獨立閱讀文件，以及刪除專案後保留的文件 | 閱讀與下載；來源保持原樣                             | 共用「個人文件」視窗可刪除自己的閱讀文件；對話仍引用的附件保留                                                         |
| 專案                   | 新建、成員／群組、文件、範本與私人對話            | 說明／共用指示、版本衝突檢查、封存／還原             | **本次新增擁有者刪除**；自動脫離對話／成果／文件，保留各自內容與直接 ACL，停止繼承專案權限；有 active 任務／生成則拒絕 |
| 知識庫                 | 容器、文件、檢索、來源頁碼                        | 容器名稱／說明／ACL、文件重新索引                    | 擁有者刪容器；文件依寫入權限刪除，清理頁面／chunk／不再引用的原始檔                                                    |
| 成果文件               | 建立、版本、PDF／Word／Markdown 匯出              | 標題／內容／版本衝突檢查、文字工具                   | 擁有者移除並撤銷分享；刪除會清理內容版本，稽核保留                                                                     |
| 分享                   | 指定收件者、期限與固定快照                        | 快照不可被發送者事後偷換內容                         | 發送者撤銷、逾期清理；改內容重新分享                                                                                   |
| 品質評測               | 題庫、匯入／匯出、方案比較、固定結果              | 題庫版本、人工評分／筆記、回饋撤回                   | **本次新增擁有者刪除評測集**；有 active jobs 不能刪；凍結結果與稽核保留，刪後一般成員不能再讀                          |
| 背景任務               | 由文件／OCR／評測產生，查詢階段與用量             | 取消／有條件重試，重新驗權限與模型設定               | 不提供任意改歷史／刪計量；避免失去費用、失敗與處理證據                                                                 |
| 系統整合               | 來源逐筆 ACL 的唯讀搜尋、狀態、版本、匯入快照     | 平台設定控制來源、群組與 SQL transport               | 不更新公文／校務來源；目前 API transport 明確顯示未支援                                                                |
| 使用者／角色／功能群組 | 首次 AD 登入建立，後台查詢用量與對話              | 分派角色、啟停角色／群組／功能、模型政策             | AD 是身分來源；不物理刪使用者或角色的稽核關聯；停用即撤權                                                              |
| 個人設定               | 當頁彈出、搜尋設定與使用量                        | 外觀／閱讀／操作／草稿／偏好                         | 還原偏好、清理本機草稿；不清理他人的資料                                                                               |
| 異動稽核／計量         | 管理員查詢、篩選及匯出                            | 只能由實際操作追加                                   | 不提供修改或刪除按鈕；保存期由正式 retention 政策管理                                                                  |

專案與評測共用 `ResourceLifecycle`，使用 transaction、SQL 條件及擁有者驗證，追加 `project.deleted`／`evaluation.deleted` 稽核。前端共用 ConfirmDialog，確認說明列出保留／撤權效果；個人文件共用同一個元件，供專案與知識庫使用。刪除評測集為 soft-delete，沒有一般使用者的回收桶還原功能；需要歷史題庫時先匯出。

多主機生成用 `ExecutorId` 與 `LeaseExpiresAt`：每 15 秒續約，有效期兩分鐘。復原採原子條件更新，只處理過期租約並追加一次 `run.recovered`，保留部分內容。跨主機取消先終止持久化狀態，執行主機的心跳會停止其 RPC。此設計避免原本只用本機記憶體判斷而誤殺另一台的生成；仍不是完整的持久聊天排程或全域 GPU 限流。

詳細驗證涵蓋私人資料隔離、editor 不能刪容器、內容保留、繼承權限撤銷、active job 阻擋與凍結結果保留。資料保存期、批次硬刪與備份還原需有明確營運政策，見 [DATABASE](DATABASE.md) 與 [IIS](../deploy/iis/README.md)。
